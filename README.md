SK AutoStrips — Official Updates
Official release channel for SK AutoStrips, an independent companion application for Tower! Simulator 3.
Download
Download SKAutoStrips_Setup.exe from Releases after the first stable release is published.
- Windows 10/11 (64-bit).
- Close Tower! Simulator 3 before updating the game plugin.
- Installer and setup guide are in English. Application language is independent.
- This release-only repository does not need to publish the application's source code.
Automatic updates
The official v0.8.19 installer embeds this repository's address. Open Settings → Automatic updates to check for newer published stable versions. Downloads are verified against the SHA-256 digest from GitHub Releases before execution.
Publishing a new version
1. Build with repository jvkrein/SK-AutoStrips-Updates embedded.
2. Go to Releases → Draft a new release.
3. Create a version tag such as v0.8.19, title it, and enter release notes.
4. Upload the standalone SKAutoStrips_Setup.exe asset (exact file name).
5. Publish a stable release. Check the API for its sha256: digest.
6. Test upgrades on Windows before announcing newer versions.
A version equal to the installed one is not an update. The app requires a newer version (such as v0.8.20) to offer automatic installation.
